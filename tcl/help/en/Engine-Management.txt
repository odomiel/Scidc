INDEX Engine Management
TITLE Engine Management

<p>
<b>Engine Management</b> is used to set up and maintain the chess engines (analysis
programs). For each engine it shows information such as name, author, web page,
country, playing strength, protocol (UCI or XBoard/WinBoard), command and working
directory.
</p>

<p>
New engines can be added, existing ones edited or removed. For each engine the
supported chess variants (&#x21d2; <a href="Chess-Variants.html">chess variants</a>)
as well as the engine-specific options (such as hash size and number of threads) can
be configured. The most recently used engines are noted.
</p>

<p>
No engines are bundled with the program itself &ndash; they are downloaded on
demand. The <b>Download engines</b> button in the engine management opens a
download dialog with one row per engine: version, size, state and the buttons
<b>Download</b> or <b>Remove</b> and <b>Project page</b>. A status line follows the
progress (download &ndash; checksum &ndash; unpack &ndash; register), and
<b>Check for newer versions</b> compares the installed engines against their
original projects. The engines come straight from those projects&rsquo; release
pages; every file is verified against a SHA-256 checksum after downloading.
</p>

<p>
On the very first program start the welcome window already offers the same
selection, so the desired engines can be set up right away.
</p>
