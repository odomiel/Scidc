INDEX Edit start position
TITLE Edit Start Position

<p>
This dialog simplifies entering a Chess 960 or Shuffle Chess start position. To do
so you simply place the pieces of White's back rank. The %::widget::mc::Ok%
button is only enabled when a valid start position is present. If the number of the
start position is known, the
<a href="Board-Setup-Dialog.html">board setup dialog</a> should be preferred for
entering the position number directly.
</p>

END
