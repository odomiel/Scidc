Database Export

Database Export writes games from a database to an output file. Among the available target formats are PGN, HTML, LaTeX and text; depending on the choice, either the entire database or only the games selected by the filter are exported.

The dialog is divided into several tabs allowing the export to be controlled in detail: file selection, general options, page and diagram layout, style, character encoding, the tags to be written, move notation, annotations and comments. This allows, for example, inserting diagrams, showing coordinates or move symbols, and defining the visibility of individual components.

For fine-grained control of the PGN output see also the PGN export settings.
