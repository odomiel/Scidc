The Tree Window

The Tree Window shows, for the current board position, all continuation moves occurring in the database together with their statistics. For each move it shows the frequency, the score (success rate) and, where available, the average rating or year.

This makes it possible to see which moves are common in a position and how successful they are – useful for opening preparation. Clicking a move plays it on the board and updates the tree for the new position. The games belonging to a move can be shown in the tree games list.
