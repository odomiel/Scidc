The Game Text Window

The Game Text Window shows the notation of the currently loaded game: the main line, all variations, comments, NAG symbols (⇒ NAG comment values) and – where present – embedded diagrams.

Clicking a move jumps to the corresponding position on the chessboard. Through the context menu and the toolbar, variations can be collapsed and expanded, the move notation switched, and comments edited. The presentation (font size, colors, notation style) follows the program settings.
