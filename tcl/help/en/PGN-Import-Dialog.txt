INDEX Game import
TITLE Game Import

<p>
<b>Game Import</b> reads games from the PGN format into a database. Import is
possible from a file or from pasted text; packed files and multiple files are also
supported.
</p>

<p>
During import Scidc checks the games and reports anomalies in a log. Fault-tolerant
processing ensures that even incomplete or slightly malformed PGN data is imported
as far as possible; the log points out skipped passages, warnings and errors.
</p>

<p>
The target database determines the format in which the games are stored
(&#x21d2; <a href="Database-Formats.html">database formats</a>). For export in the
opposite direction use the <a href="Database-Export-Dialog.html">database export</a>.
</p>
