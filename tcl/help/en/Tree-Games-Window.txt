INDEX Tree games window
TITLE The Tree Games List

<p>
The <b>Tree Games List</b> shows the games matching the current selection in the
<a href="Tree-Window.html">tree</a> &ndash; that is, all games of the database that
pass through the current position or the selected move.
</p>

<p>
The list behaves like the regular <a href="Game-List-Window.html">game list</a>: it
can be sorted, and double-clicking loads the respective game. This makes it easy to
find concrete example games for an opening position.
</p>
