INDEX Comment editor
TITLE Comment Editor

<p>
This dialog is opened in the game editor in one of the following ways:
</p>

<ul>
  <li style="margin-bottom:0.5em;">
    With the keyboard shortcut
    <kbd class='key'>Ctrl</kbd>+<kbd class='key'>K</kbd>
    to edit a comment after the move.
  </li>
  <li style="margin-bottom:0.5em;">
    With the keyboard shortcut
    <kbd class='key'>Ctrl</kbd>+<kbd class='key'>Shift</kbd>+<kbd class='key'>K</kbd>
    to edit a comment before the move; or to edit a leading comment of a variation
    when the input cursor is positioned before the first move of the variation (or
    main line).
  </li>
  <li style="margin-bottom:0.5em;">
    Through the context menu of the game editor.
  </li>
  <li>
    By clicking on a comment. In this case the dialog automatically switches, already
    when opening, to the language of the selected comment.
  </li>
</ul>

<p>
Opening the comment editor is only possible while a game is being edited in the game
editor.
</p>

<p>
The comment editor consists of five regions:
</p>

<ul style='list-style-type: none'><li><img src="images/comment-editor.png" alt="" /></li></ul>

<ul>
  <li><a href="#Language">Language selection</a> (top toolbar)</li>
  <li><a href="#Formatting">Text formatting</a> (left toolbar)</li>
  <li><a href="#Text">Text field</a></li>
  <li><a href="#Buttons">Buttons for text field control</a> (buttons to the right of the text field)</li>
  <li><a href="#Dialog">Dialog buttons</a> (buttons at the bottom)</li>
</ul>

<h2 id="Language">Language selection</h2>

<p>
The comment editor allows entering and modifying comments in the game text in
different language versions. All European languages are supported. The symbol
<img src="../images/green-plus.png" alt="" /> opens a combobox for adding another
language.
</p>

<h2 id="Formatting">Text formatting</h2>

<p>
Comments can be formatted:
</p>

<ul>
  <li><img src="../images/format-bold.png" alt="" />&ensp;Bold</li>
  <li><img src="../images/format-italic.png" alt="" />&ensp;Italic</li>
  <li><img src="../images/format-underline.png" alt="" />&ensp;Underline</li>
</ul>

<p>
All combinations of these formattings are allowed. To apply them, a text region is
selected (&#x21d2; <a href="#Control">Control in the text field</a>) and then the
corresponding symbol is chosen. Applying a formatting affects the entire selected
region. Each time the input cursor is repositioned in the text field, the formatting
of the character to the left of the input cursor is shown accordingly. When entering
text, the formatting to the left of the input cursor is continued, but not the
formatting to the right of the input cursor.
</p>

<p>
There is one exception: figurines (graphical pieces, such as <span class='chess'>&#x2654;</span>) and
position evaluation symbols (such as &#x00b1;) are not subject to italic formatting
nor to underline formatting.
</p>

<div class='annotation'><img src='../images/annotation.png' style='float:left; margin:0 1em 0 0' alt='annotation' />
These formattings can only be stored in the
<a href="Database-Formats.html#Scidc">Scidc database format</a>.
When converting to the
<a href="Database-Formats.html#Scid">Scid format</a>,
or when exporting to the
<a href="Database-Formats.html#PGN">PGN format</a> (exception:
one of the options <i>Write comment in HTML format</i>
or <i>Use Scidb import format</i> is used) all formattings are lost.
</div>

<p>
The comment editor marks all symbols recognized as <a href="NAG-Comments.txt">NAG</a>
with a dark red foreground for better visibility. When the mouse pointer is held over
such a symbol, a tooltip with the meaning of this symbol is shown.
</p>

<h4 id="Control:Mouse">Input cursor control with the mouse</h4>

<p>
Clicking with the left mouse button positions the input cursor before the character
under the mouse pointer, sets the input focus to the text field, and deselects any
selected text. Dragging with the mouse while the left mouse button is held selects
the text between the input cursor and the character under the mouse pointer.
</p>

<p>
Double-clicking with the left mouse button selects the word under the mouse pointer
and positions the input cursor at the beginning of the word. Dragging with the mouse
while the left mouse button is held after a double click selects the words between the
input cursor and the character under the mouse pointer.
</p>

<p>
A triple click with the left mouse button selects the line under the mouse pointer
and positions the input cursor at the end of the line. Dragging with the mouse while
the left mouse button is held after a triple click selects all lines between the input
cursor and the character under the mouse pointer.
</p>

<p>
The end of a text selection can be extended by dragging the mouse with the left mouse
button held; this affects the end of the selection that was closest to the mouse
pointer during the click. If a double click was performed before dragging, then
extension happens in word units; after a preceding triple click, extension happens in
line units.
</p>

<p>
Clicking the left mouse button while the <kbd class='key'>Ctrl</kbd> key is held
positions the input cursor without affecting the text selection.
</p>

<p>
The visible text excerpt in the text field can be changed by dragging with the middle
mouse button held. If the middle mouse button is clicked without dragging the mouse,
then the current X text selection of the clipboard is inserted at the position of the
input cursor (Linux/Unix only).
</p>

<p>
If the mouse is dragged out of the text window area while the left mouse button is
held, then the text scrolls automatically to make more text visible.
</p>

<h3 id="Text:Hyperlinks">Hyperlinks</h3>

<p>
The editor allows entering web links (hyperlinks) as well as entering clickable email
addresses. The syntax for entry is borrowed from the wiki syntax:
</p>

<ol>
  <li style="text-align: left">
    <code>[[http://scidb.sourceforge.net]]</code> links the URL
    <a href="http://scidb.sourceforge.net" target="blank_">http://scidb.sourceforge.net&nbsp;<span class="awesome">&#xf08e;</span></a>
    to the web page <code>http://scidb.sourceforge.net</code>.
  </li>
  <li style="text-align: left">
    <code>[[http://scidb.sourceforge.net][Scidc]]</code> links the word
    <a href="http://scidb.sourceforge.net" target="blank_">Scidc&nbsp;<span class="awesome">&#xf08e;</span></a> to the web page
    <code>http://scidb.sourceforge.net</code>. Alternatively the syntax
    <code>[[http://scidb.sourceforge.net|Scidc]]</code> can also be used.
  </li>
  <li style="text-align: left">
    <code>[[fred@feuerstein.net][Fred Feuerstein]]</code> refers to the email address
    of <a href="mailto:fred@feuerstein.net" target="blank_">Fred Feuerstein&nbsp;<span class="awesome">&#xf112;</span></a>.
  </li>
</ol>

<p>
To make entering a link easier, a helper function exists in the context menu.
</p>

<h3 id="Text:Emoticons">Smileys</h3>

<p>
The editor recognizes smileys, provided smiley recognition has been enabled in the
game editor, i.e. textual smiley codes &ndash; such as
<span style='white-space:nowrap;'><code>:-)</code></span> &ndash; are shown with the
corresponding pictogram (e.g. <img src="../images/smiley.png" alt="" />), provided
recognition was possible. For this, the display of smileys in the comment editor must
also be enabled (&#x21d2; <a href="#Menu">Context menu</a>). Entering a smiley is
easiest with the help of the context menu. Smiley codes entered in the text field are
not recognized automatically right away, but only after a refresh of the entire
display, such as after a language change, or after saving (with
<span class='menuitem'>Apply</span>).
</p>

<p>
When smiley pictograms are shown, they are of course not subject to any text
formatting. However, it should be noted that the text display of the smiley codes is
subject to the set formatting.
</p>

<p>
Smileys are stored in textual form, i.e. they are transferable to other database
formats.
</p>

<h3 id="Text:Menu">Context menu</h3>

The context menu in the text field offers the following functions:

<ul style='list-style-type: none'><li><img src="images/comment-editor-menu.png" alt="" /></li></ul>

<p>
<span class='menuitem'>Copy</span>
Copy selected text to the clipboard. This menu item is only available when text is
selected.
</p>

<p>
<span class='menuitem'>Cut</span>
Delete selected text and copy it to the clipboard. This menu item is only available
when text is selected.
</p>

<p>
<span class='menuitem'>Paste</span>
Insert text from the clipboard at the input cursor position. This menu item is only
available when text is present in the clipboard.
</p>

<p>
<span class='menuitem'>Insert symbol</span>
Insert a symbol at the input cursor position.
</p>

<p>
<span class='menuitem'>Insert smiley</span>
Insert an emoticon (smiley) at the input cursor position.
</p>

<p>
<span class='menuitem'>Insert link</span>
Insert a hyperlink at the input cursor position.
</p>

<p>
<span class='menuitem'>Format text</span>
Format the selected text: bold, italic, or underlined.
</p>

<p>
<span class='menuitem'>Copy text to</span>
Copy the entire text to another language region. The text is appended to any text that
may already be present.
</p>

<p>
<span class='menuitem'>Undo</span>
Undo the last action in the text area.
</p>

<p>
<span class='menuitem'>Redo</span>
Redo the previous undo (&#x21d2; <span class='menuitem'>Undo</span>).
</p>

<p>
<span class='menuitem'>Select all</span>
Select the entire text.
</p>

<p>
<span class='menuitem'>Delete</span>
Delete the entire text.
</p>

<p>
<span class='menuitem'>Revert</span>
Restore the original text - either the starting text, or the text after the last save.
This menu item is only available when the current text differs from the restore text.
</p>

<p>
<span class='menuitem'>Switch language</span>
Select a different language.
</p>

<p>
<span class='menuitem'>Add language</span>
Add a language.
</p>

<p>
<span class='menuitem'>Show smileys</span>
When enabled, the recognized smileys are shown with pictograms, otherwise the text for
this smiley is shown. This menu item is only available when automatic recognition of
smileys is enabled in the game editor.
</p>

<h2 id="Buttons">Buttons for text field control</h2>

<p>
<span class='menuitem'>Insert symbol</span>
Quick entry of a symbol at the current input cursor position, such as a position
evaluation, or another special character.
</p>

<p>
<span class='menuitem'>Delete</span>
Delete the entire text (of the current language).
</p>

<p>
<span class='menuitem'>Revert</span>
Restore the original text for the current language. This button is only active when
the new text differs from the original text. As soon as the text is saved, this becomes
the new original text.
</p>

<h2 id="Dialog">Dialog buttons</h2>

<p>
<span class='menuitem'>OK</span>
Save the texts of all selected languages and close the dialog.
</p>

<p>
<span class='menuitem'>Apply</span>
Save the texts of all selected languages without leaving the dialog (for previewing in
the game editor).
</p>

<p>
<span class='menuitem'>Cancel</span>
Close the dialog without saving, i.e. any changes that may exist are discarded. If a
save was already done before with <span class='menuitem'>Apply</span>, then the
last-saved text is retained.
</p>
