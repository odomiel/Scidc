Game Import

Game Import reads games from the PGN format into a database. Import is possible from a file or from pasted text; packed files and multiple files are also supported.

During import Scidc checks the games and reports anomalies in a log. Fault-tolerant processing ensures that even incomplete or slightly malformed PGN data is imported as far as possible; the log points out skipped passages, warnings and errors.

The target database determines the format in which the games are stored (⇒ database formats). For export in the opposite direction use the database export.
