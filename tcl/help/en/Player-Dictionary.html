The Player Dictionary

The Player Dictionary is a built-in master database for chess players. It provides verified data such as FIDE ID, title, federation, sex and ratings, and serves as a reference work when entering and maintaining games.

A filter narrows the display – for example by organization ID, titles, rating ranges or a period of years. The player name search is case-insensitive and supports pattern matching (⇒ Pattern matching).

The rating lists can be updated directly from within the application: via Update Player Lists Scidc downloads the current FIDE and DWZ data one after another and reads them in. When saving a game, the save game dialog proposes matching entries from the player dictionary.
