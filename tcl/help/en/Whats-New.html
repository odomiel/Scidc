What's new?

Scidc is a fork of Scidb r1531. The following has been added, changed, or fixed since the fork:

New Features

  • .si5 format: read, write, export and create new databases (support still under development)
  • Night Mode (dark mode): dark colour scheme for the entire user interface
  • Engine management with download dialog: six engines (Stockfish, Fairy-Stockfish, RubiChess, Stormphrax, Viridithas, Arasan) can be fetched straight from their original projects – with version, size, checksum and a check for newer releases; the former Sjeng engine is gone
  • Welcome window on first start: language choice and engine selection in a single window, the language switches over immediately without closing the window
  • FIDE player dictionary: one-click update directly in the app
  • DWZ ratings (German chess rating) integrated as data source
  • Antichess added as chess variant
  • "Clear entire history" option in start screen context menu
  • .si5 added to file type assignment dialog
  • Debugging submenu under Settings
  • Improved name search in the Save Game dialog: case-insensitive substring and word matching (first and last name in any order, no comma needed), starting at 3 characters
  • Engine download dialog now shows when an installed engine is outdated, and the button updates it in place

Removed Features

  • Player photos subsystem removed
  • Engine console removed from menu
  • Engine dictionary removed
  • "Theme" menu removed: the appearance now follows the colour scheme (dark for night mode, light otherwise). The clearlooks and scidblue themes and the "Scidc's Style Menu" and "Default Style Menu" entries are gone; the two light colour schemes are now labelled "(Light)"

Bug Fixes

  • Fixed crash in file selection dialog
  • Fixed missing engine entries
  • Various SI5 export and import bugs fixed
  • Numerous dark mode rendering issues fixed
  • Engines fetched with the download dialog now stay: the entry was kept in memory only and was gone after the next start
  • The engine list is no longer lost when the program is closed after saving in engine management
  • The XML parser (expat) and the compression library (zlib) are now part of the program itself, at 2.8.4 and 1.3.2 respectively. Until now the build host's versions were shipped (2.7.4 and 1.3.1); expat was missing five security fixes, zlib the follow-up work of a security audit. Both process data from foreign files: comments from database files, SVG graphics, images and the help pages.
