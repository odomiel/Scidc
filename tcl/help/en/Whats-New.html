What's new?

Scidc is a fork of Scidb r1531. The following has been added, changed, or fixed since the fork:

New Features

  • .si5 format: read, write, export and create new databases (support still under development)
  • Night Mode (dark mode): new TTK theme with dark color scheme
  • Stockfish 18 and Fairy-Stockfish 14 replace the former Sjeng engine
  • FIDE player dictionary: one-click update directly in the app
  • DWZ ratings (German chess rating) integrated as data source
  • Antichess added as chess variant
  • "Clear entire history" option in start screen context menu
  • .si5 added to file type assignment dialog
  • Debugging submenu under Settings
  • Improved name search in the Save Game dialog: case-insensitive substring and word matching (first and last name in any order, no comma needed), starting at 3 characters

Removed Features

  • Player photos subsystem removed
  • Engine console removed from menu
  • Engine dictionary removed

Bug Fixes

  • Fixed crash in file selection dialog
  • Fixed missing engine entries
  • Various SI5 export and import bugs fixed
  • Numerous dark mode rendering issues fixed
  • First-run language selection dialog fixed
