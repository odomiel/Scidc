The Chessboard Window

The Chessboard Window is the central display element and shows the current position of the loaded game. Below it are navigation buttons for stepping move by move or jumping to the start or end of the game.

Moves can be played directly on the board with the mouse; they are then entered into the game notation. The appearance and behaviour of the board – piece set, board theme, coordinate display, marker arrows and square colors – can be adjusted through the board themes and the settings. Markers (arrows, colored squares) are set with the square marker palette.

An arbitrary starting position can be created with the board setup.
