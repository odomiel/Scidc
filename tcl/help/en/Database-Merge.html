Merging Games

With the Merge function several games can be merged into a single game with variations. This is useful for turning many individual games into a compact opening tree as an annotated game.

The merge can start from the current board position or from the initial position. Options allow transpositions to be included or excluded as well as limiting the variation depth and the maximal variation length. A preview shows the result before saving.

The result can be saved as a new game or merged into an existing game. While the dialog is open, the game in question is locked against concurrent changes. Only games of the same chess variant can be merged.
