Engine Management

Engine Management is used to set up and maintain the chess engines (analysis programs). For each engine it shows information such as name, author, web page, country, playing strength, protocol (UCI or XBoard/WinBoard), command and working directory.

New engines can be added, existing ones edited or removed. For each engine the supported chess variants (⇒ chess variants) as well as the engine-specific options (such as hash size and number of threads) can be configured. The most recently used engines are noted.

No engines are bundled with the program itself – they are downloaded on demand. The Download engines button in the engine management opens a download dialog with one row per engine: version, size, state and the buttons Download or Remove and Project page. A status line follows the progress (download – checksum – unpack – register), and Check for newer versions compares the installed engines against their original projects. The engines come straight from those projects’ release pages; every file is verified against a SHA-256 checksum after downloading.

On the very first program start the welcome window already offers the same selection, so the desired engines can be set up right away.
