Square Marker Palette

This palette can be opened on the chessboard window either with the keyboard shortcut Ctrl+M or through the context menu of the game editor (⇒ Square marker palette), but only while a game is being edited in the game editor.

The palette allows choosing the color of the marker as well as the marker type. The color and type selection was kept identical to the chess database application Scid .

The palette is only visible while the chessboard window is active.

In the game editor markers are indicated with the symbol . The tooltip shows the code as it appears in the PGN format.

The following describes how markers are set. Setting a marker on the chessboard is only possible while a game is being edited in the game editor.

  • Mark a square with a symbol
  • Mark a move with an arrow

Mark a square with a symbol

A double click, or two clicks on a square while holding the Ctrl key, marks this square with the selected symbol in the selected color. The marker is removed by another double click while holding Ctrl with the same symbol and the same color. Note that after the first click the marker for the selected square is shown, and only after the second click does the symbol become visible. A square marker can be overwritten by another square marker. Multiple markers on one square are not possible.

Mark a move with an arrow

An arrow is set by a click while holding the Ctrl key on the source square (the marker for the selected square is now shown) and a second click while holding Ctrl on the target square. The arrow is shown in the selected color. A move marker is removed by setting an arrow of the same color again on the same source and target squares. A move marker can be replaced by a move marker of a different color.
