Novità 

Scidc è un fork di Scidb r1531. Le seguenti funzionalità sono state aggiunte, modificate o corrette dal fork:

Nuove Funzionalità

  • Formato .si5: lettura, scrittura, esportazione e creazione di nuovi database (supporto ancora in sviluppo)
  • Night Mode (dark mode): dark colour scheme for the entire user interface
  • Engine management with download dialog: six engines (Stockfish, Fairy-Stockfish, RubiChess, Stormphrax, Viridithas, Arasan) can be fetched straight from their original projects – with version, size, checksum and a check for newer releases; the former Sjeng engine is gone
  • Welcome window on first start: language choice and engine selection in a single window, the language switches over immediately without closing the window
  • Dizionario giocatori FIDE: aggiornamento con un clic direttamente nell'app
  • Valutazioni DWZ (classificazione scacchistica tedesca) integrate come fonte dati
  • Antiscacchi aggiunto come variante degli scacchi
  • Opzione "Cancella intera cronologia" nel menu contestuale della schermata iniziale
  • .si5 aggiunto alla finestra di assegnazione tipi di file
  • Sottomenu di debug sotto Impostazioni
  • Ricerca dei nomi migliorata nella finestra Salva partita: senza distinzione tra maiuscole e minuscole, ricerca per sottostringa e per parole (nome e cognome in qualsiasi ordine, senza virgola), a partire da 3 caratteri
  • Engine download dialog now shows when an installed engine is outdated, and the button updates it in place

Funzionalità Rimosse

  • Sottosistema foto giocatori rimosso
  • Console motore rimossa dal menu
  • Dizionario motori rimosso
  • "Theme" menu removed: the appearance now follows the colour scheme (dark for night mode, light otherwise). The clearlooks and scidblue themes and the "Scidc's Style Menu" and "Default Style Menu" entries are gone; the two light colour schemes are now labelled "(Light)"

Correzioni di Bug

  • Risolto un crash nella finestra di selezione dei file
  • Aggiunte voci di motore mancanti
  • Vari bug di esportazione e importazione SI5 corretti
  • Numerosi problemi di visualizzazione in modalità scura corretti
  • Engines fetched with the download dialog now stay: the entry was kept in memory only and was gone after the next start
  • The engine list is no longer lost when the program is closed after saving in engine management
  • The XML parser (expat) is now part of the program itself and up to date at 2.8.4. Until now the build host's version was shipped (2.7.4), which was missing five security fixes. Comments from foreign database files, SVG graphics and the help pages all pass through this parser.
